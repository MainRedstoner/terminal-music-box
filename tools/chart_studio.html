使用说明 / 键位

流程：① 点「延迟校准」测一次按键延迟（每台机器/浏览器一次即可）； ② 演奏模式下边听边按 A S D J K L 放音符，空格 暂停/继续， 暂停中按键 = 在当前位置精确放音符；③ Tab 切到编辑模式微调：拖动改 时间/轨道，方向键 ±10ms / 换轨，L 双押、U 解除、 Del 删除、Ctrl+Z 撤销；④ 「歌曲信息 / 导出」导出两个 json，和音频一起打包：

python tools/make_pack.py --src packs/my_song --audio audio.m4s

m4s 提示：浏览器解不了 B 站 .m4s 分段容器，先转封装： ffmpeg -i in.m4s -c:a copy out.m4a

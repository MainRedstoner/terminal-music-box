几点细节

校准：测得的是「音频输出延迟 + 你的反应延迟」。降速作谱时，反应分量会按速率缩放，输出延迟不变，所以音符始终落在你听到的位置。

暂停中放音符：直接落在播放头位置，不再扣除反应延迟；想精确对齐时，暂停后放音符更可靠。

网格：格距按 BPM 的整数分割算（1 拍 / 1/2 / 1/4 / 1/8 拍），相位把整张网格左右挪。BPM 填错时网格会跟着错，先对一下节拍器。

量化：黄色刻度是预览目标，拖动「强度」可以让音符只向网格靠一部分；「量化全部」才真正改写时间，可 Ctrl+Z 撤销。同轨落在同一时间点的重复音符会被合并。

偏移：正数把音符整体往后推，用来修「整体早/晚」；「仅偏移」只应用偏移，不动网格。

草稿：按「文件名 + 时长」自动保存在浏览器里，重新选同一个音频即可恢复；换设备不会同步。

m4s：浏览器解不了 B 站分段容器，先转封装： ffmpeg -i in.m4s -c:a copy out.m4a

打包：生成 .tmbp（zip 内含 manifest.json、chart.json、音频），丢进游戏根目录的 external_songs/ 即可。音频优先编成 Opus 96 kbps；浏览器不支持 WebCodecs 时退回原文件，再不行退回 WAV。打包好的包可以直接用顶栏「音乐包」重新打开继续改。
